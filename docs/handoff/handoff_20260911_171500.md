## 1. 变更清单与架构决策

### 1.1 冗余 UI 元素清理 (Clean Sheet)
1. **删除全量 35 列说明条**：移除了 `.yn-bem-table-category-legend` 及其 CSS 与 DOM 渲染，不再侵占表格上方宝贵的垂直视野。
2. **删除顶部子栏推断按钮**：移除了顶部子栏的 `div "已选: 121 笔 ✨ AI 智能推断"`，功能全部收拢至 Gemini 侧边栏与悬浮岛中。
3. **删除顶部批量修改按钮**：移除了顶部顶栏的 `⚙️ 批量修改属性` 按钮，主触发入口由底部悬浮岛 (`Floating Action Island`) 承载。
4. **彻底隐藏右下角副驾 0 浮标**：在 `floatingDock.ts` 中当 `visibleCount === 0` 时设置 `display: none`，并在批量编辑模态框内部样式强制声明 `#autopilot-floating-dock { display: none !important; }`。
5. **删除品牌标题徽章**：移除了 `.yn-bem-brand-badge`（`121 笔费用 (137 张发票)`），保持标题清爽干净。
6. **彻底剔除视图切换下拉器**：删除 `CLEAN_COLUMN_DEFINITIONS` 与 `viewMode` 状态，永久固定并聚焦于功能完备的全量 35 列编辑表格。

### 1.2 BUG 1 根因分析与彻底修复 (Checkbox & Selection Sync)
- **根本原因**：`updateAllCheckboxStates()` 中使用 `container.querySelectorAll('.yn-bem-row-cb')` 查询行复选框，但表格渲染时实际采用的类名为 `.yn-bem-record-cb`。导致 DOM 查询返回空集合，点击“全不选”时行复选框无法被清空，且未调用 `tr.classList.toggle('is-selected')` 导致多行蓝色高亮持续残留。
- **修复方案**：
  1. 将查询选择器统一纠正为 `.yn-bem-record-cb`；
  2. 遍历所有 `tr.yn-bem-data-row` 数据行，严格根据 `modalState.selectedRecordIds.has(rid)` 动态切换 `is-selected`；
  3. 修复分组复选框 (`.yn-bem-group-cb`) 同步逻辑与半选 (`indeterminate`) 状态计算。

### 1.3 批量设置弹窗模块化独立应用 (Modular Selective Apply)
- **删除冗余字段**：彻底移除了不再适用的“出差区分”（异地出差/市内/日常）下拉选择器。
- **模块化独立复选框**：
  - `[☑] 批量修改费用说明 (备注信息)` (`#yn-bem-chk-apply-desc`)
  - `[☑] 变更报销类型与专属参数` (`#yn-bem-chk-apply-type`)
  - `[☑] 统一业务日期与交通地址` (`#yn-bem-chk-apply-date`)
- **严格说明格式**：
  - 本人报销：`[${project}]`，若有备注追加为 `[${project}]-[${remark}]`；
  - 代外驻报销：`[外驻:${name}]-[${project}]`，若有备注追加为 `[外驻:${name}]-[${project}]-[${remark}]`；
  - 严禁输出空括号 `[]` 或多余连字符 `-`；
- **独立应用执行守卫**：在 `handleApply()` 中分别判断上述三个复选框的选中状态，仅修改用户勾选的模块，杜绝相互覆盖。

### 1.4 Gemini 风格复合输入卡片 (Gemini Composer Card - Screenshot 3)
- **输入卡片结构**：
  1. **顶部费用上下文胶囊**：当勾选费用记录且未被关闭时，在卡片顶部渲染 `📎 已选中费用条目 X 笔，金额 ¥Y [✕]`，点击 `✕` 仅临时脱离当前会话上下文而不影响表格勾选；
  2. **附件缩略流**：支持图片缩略图卡片与文件文档卡片，鼠标悬浮显示 `✕` 删除按钮，点击图片支持 Lightbox 全屏放大遮罩；
  3. **多模态文件上传与拖拽**：支持点击左下角 `＋` 按钮选择文件，或直接将图片、票据截图拖入卡片区域，自动异步读取为 Base64 DataURL 或文件元数据；
  4. **右下角操作组**：模型选择下拉框（`Flash` / `Pro` / `Flash Lite`）与蓝色高质感圆形发送按钮 `↑`（支持 Enter 发送，Shift+Enter 换行）。

### 1.5 连续多轮会话管理与会话历史 (Screenshot 4)
- **头部会话菜单**：顶栏右侧新增 `≡ 会话 ▾` 下拉菜单：
  - `📝 Start new chat`（开启全新对话会话）；
  - 最近会话列表（显示会话标题、激活指示器、单会话删除按钮 `✕`）；
  - `⚙️ 副驾配置与帮助`。
- **持久化机制**：所有会话自动序列化存储至 `localStorage` 键 `fssc_autopilot_chat_sessions`，页面重载与弹窗开关无缝延续。
- **气泡流体验**：
  - 用户气泡：靠右显示，自动展示携带的费用上下文与附件缩略图；
  - 副驾气泡：靠左显示，带有 Sparkle 徽标与轻量 Markdown 格式化解析。
