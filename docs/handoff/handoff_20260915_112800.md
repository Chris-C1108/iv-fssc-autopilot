## 2. 本阶段核心完成工作与业务突破

### 2.1 宿主系统 OCR 单张发票裁切切片精确呈现与双模预览 (v4.62.4)
- **逆向发现**：通过抓包与分析宿主验票页 `checkInvoicePage`：
  - `inv.filePath` 为用户上传的原始全图（常包含多张票据拍摄整张桌面，分辨率达 5712×4284）；
  - `inv.videoAddress` 为宿主系统后台 OCR 自动识别并切片裁切后的**单张发票特写图像**；
  - 宿主系统官方轮播组件展示单发票时使用的正是 `inv.videoAddress`！
- **双轨抽取与持久化**：
  - 在 `src/services/expenseService.ts` 中新增 `rawAttachmentId`，并发提取切片（`videoAddress`）与原图（`filePath`）；
- **双模自适应与就地无缝切换**：
  - 预览浮窗默认展示 **`✂️ OCR裁切特写`**，彻底看清票面明细；
  - 底部动态提供 **`查看拍摄原图 📷` / `查看裁切单票 ✂️`** 切换按钮，点击即刻就地无缝重载；
  - 内置自动容灾降级：若裁切切片偶发 404/加载失败，自动回退原件大图，保证绝不白屏。

### 2.2 发票浮窗平滑移入与 280ms 延迟防抖常驻机制 (v4.62.5)
- **痛点根除**：此前鼠标离开 `🖼️` 图标时浮窗瞬时销毁，用户无法移入浮窗操作链接；
- **双轨感知与延时桥接**：
  - 在 `src/ui/batchEditExpenseModal.ts` 中维护 `isMouseOverPopover` 与 `isMouseOverBtn`；
  - 离开图标时启动 280ms 定时器防抖；若用户在 280ms 内移入 Popover 内部，`mouseenter` 立即取消定时器，浮窗平滑常驻；
  - 离开浮窗且未回到图标时，才延迟 280ms 平滑关闭。

### 2.3 发票浮窗高清自适应大视口重构 (v4.62.5)
- **痛点根除**：原固定限高 320px 过于局促，无法看清复杂小票文字；
- **响应式视口放宽**：
  - 宽度改为自适应（`width: auto; min-width: 360px; max-width: min(720px, 94vw);`）；
  - 图片容器高度提升至 `max-height: min(620px, 75vh);`，图片最大高度达 600px；
  - 结合 `imgEl.onload` 完成时自动微调视口贴边与防溢出坐标，大图绝不超出屏幕。

### 2.4 表格分组栏对比度强化与结构层次分明 (v4.62.5)
- 主分组栏 `.yn-bem-group-header-row` 与粘性单元格统一采用高辨识度冷灰岩底色 `#edf2f7 !important`；
- 左侧增设醒目的皇家蓝指示线条 `border-left: 4px solid #2563eb !important;`，标题文本采用深板岩加粗 `#0f172a`；
- 二级子分组头采用 `#f1f5f9` 搭配 `#64748b` 侧标，与纯白明细条目形成极佳的阶梯对比。

### 2.5 表头筛选菜单绝对高层级防护 (z-index: 10001)
- **Stacking Context 穿透**：表格 `<th>` 自身带有 `position: sticky; z-index: 10`，其内部绝对定位浮层原本被其他 `z-index: 20` 的粘性列遮挡；
- **解决方案**：在表头点击展开筛选时，动态为当前 `<th>` 注入类名 `.yn-bem-th-popover-open` 并赋予 `z-index: 10000 !important;`，浮窗赋予 `z-index: 10001 !important;`，彻底击穿局部层叠上下文，绝对高于任何表格 sticky 列与数据单元格。
