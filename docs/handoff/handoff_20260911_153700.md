## 1. 核心架构与模式变更 (Google AI Agent Patterns 1 & 2)

参考 [Google Developers Blog: 4 engineering patterns behind the strongest AI Agents Challenge submissions](https://developers.googleblog.com/4-engineering-patterns-behind-the-strongest-ai-agents-challenge-submissions/)：

### 1.1 Pattern 1: Bidirectional Tool Layer (`src/services/batchEditTools.ts`)
- 将批量修改费用信息页的 AI 与业务能力抽象为标准化内部 Tool Layer：
  - `inferSelectedFields`: 智能推断已选费用专属字段
  - `parseItinerary`: 概率推理/正则解析多轮出差行程排期
  - `clusterTrips`: 自动聚类出差区间与日常费用
  - `createBillDraft`: 批量创建 SC (出差申请单)、BC (出差费用报销单)、BJ (经费报销单) 草稿
- **双向暴露**：不仅由内部 UI 组件调用，同时挂载至 `window.__batchEditTools`，供外部 Agent / WebMCP 副驾直接编程调用。

### 1.2 Pattern 2: Event-Driven Concurrency (`BatchEditEventBus`)
- 引入轻量级 Topic Pub/Sub 事件总线 `BatchEditEventBus`：
  - `SELECTION_CHANGED`: 费用勾选变更事件，并行通知表格统计徽章与 AI 面板上下文药丸
  - `INFERENCE_START` / `INFERENCE_COMPLETE`: 推断事件，局部更新行数据并向 AI 面板卡片流追加成功卡片
  - `TRIPS_CLUSTERED`: Trip 聚类完成事件
  - `BILL_DRAFT_CREATED`: 草稿单生成事件
- 彻底解耦 UI 渲染与异步业务流，避免串行阻塞与全量重绘。

## 2. UI/UX 体验重构

### 2.1 精简双行顶栏 (Compact 2-Row Top Bar)
- **第 1 行（核心元数据与检索区）**：
  - 品牌徽章：最早开票日聚合统计、发票张数、开票/行程预警指示
  - 模糊搜索输入框 (250ms 防抖)
  - 分组模式选择器 (`按 Trip 轮次` / `按费用类型` / `Trip+类型两级` / `平铺`) + 全部展开/折叠
  - 模态关闭按钮
- **第 2 行（快捷选择与操作开关区）**：
  - 快速选择：`全选` / `全不选` / `反选` / `仅选待补(N)` / `仅选预警(M)` / 筛选下拉
  - **`⚙️ 批量设置 ▾` 开关按钮**
  - **`✦ AI 助手 ✨` 开关按钮**

### 2.2 批量设置下拉面板 (`.yn-bem-batch-settings-panel`)
- 点击顶栏 `⚙️ 批量设置` 展开平滑下滑面板：
  - 出差区分 (异地出差 / 市内日常)
  - 报销类型 (外驻代报销 / 本人报销) + 外驻人名动态输入
  - 归属项目实时检索下拉
  - 变更报销类型下拉
  - 自定义备注
  - 批量业务日期与按最早开票日同步
  - **代外驻报销格式预设**：`[外驻:${name}] ${project} ${remark}` + 实时清洗预览
  - 专属动态必填字段卡片 (住宿/飞机/火车/交通/通信)
  - `✨ AI 智能推断` + `应用到已选 (预览更新)` 按钮

### 2.3 Gemini 风格 AI 助手侧滑面板 (`.yn-bem-ai-panel`)
- 点击 `✦ AI 助手` 从右侧平滑滑出 380px 面板，表格区域自适应宽度（`flex: 1; min-width: 0;`）：
  - **Gemini 经典 Logo 与问候语**：`Ask away, ${社员名}!`
  - **上下文感知药丸 (Context Pill)**：`📎 已携带 N 笔已选费用数据 (¥金额)`，随选择实时响应
  - **4 个固定快捷功能气泡按钮 (Suggestion Chips)**：
    1. `🔮 智能推断已选费用必填项`
    2. `📋 粘贴排期规划 Trip 行程`
    3. `✨ 全流程智能规划 (行程与日常)`
    4. `🚀 决策复核与极速建单 (HITL)`
  - **动态卡片流 (Feed Stream)**：实时流式追加操作结果与小提示
  - **底部自然语言指令输入框**：输入指令（如：*李建勇外驻深圳X2605*）按回车/点击发送即执行推理

## 3. 性能优化 (4 级精细度局部刷新)

| 刷新级别 | 执行内容 | 耗时对比 |
|:--|:--|:--|
| `CHECKBOXES` | 纯 DOM 操作更新 `.checked` 与 `.indeterminate`，同步 Footer 与 AI 上下文 | ~200ms → **< 5ms** |
| `STATS` | 仅更新 Footer 统计与说明预览药丸，配合 `requestAnimationFrame` 防抖 | ~200ms → **16ms** |
| `ROWS` | 局部替换 `#yn-bem-table-wrap` 的 table HTML，保留顶栏和配置面板 DOM | ~200ms → **~120ms** |
| `FULL` | 结构变更时全量重绘 | 按需调用 |
