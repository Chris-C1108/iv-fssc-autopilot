## 一、本次版本演进清单

### 1. 住宿费多间房超标误报根治与错误精准定位穿透 (`v4.52.2`)
- **多间房超标计算纠偏**：
  - 发票合报多间房（如 3 间 4 晚共 ¥4265.47）时，原计算公式漏乘房间数导致间夜单价被算成 `¥4265.47 / 4 = ¥1066.37`，误报超出标准（¥700/晚），触发后端刚性校验 `OVER_STANDARD_DESCRIPTION` 必填强阻断；
  - 在 `src/services/expenseService.ts` 中修正为：`unitPrice = amount / (nights * rooms)`（实测 `¥4265.47 / (4 * 3) = ¥355.45/间夜`），彻底消除误报。
- **保存失败条目精准高亮与错误穿透**：
  - 在 `src/services/expenseRecordDomService.ts` 与 `src/ui/batchEditExpenseModal.ts` 中建立完整错误回溯链路：
  - 批量保存返回错误信息时，精确解析提取失败的单据 ID / 行索引与具体错误原因；
  - 模态框顶部弹出红色显式错误横幅（`.yn-bem-error-banner`），罗列具体失败条目；
  - 表格对应出错行自动添加红色高亮背景（`.yn-bem-row-error`）与跳动警示徽标（`.yn-bem-error-badge`），并自动平滑滚动聚焦到出错行。

### 2. 出差排期规划人在回路 (HITL) 确认体系 (`v4.52.3`)
- **拒绝大模型私自篡改表格**：
  - 针对大模型 `parseItineraryWithAiDetailed` 推断出的出差排期，严格恪守 `AGENTS.md` 0.2 人在回路 (HITL) 规约，严禁大模型解析完成后直接私自覆盖表格中的 Trip 状态；
- **交互式结构化确认卡片 (`TripPlanConfirmationAction`)**：
  - 在 `src/ui/AssistantChatPanel.tsx` 中定义 `TripPlanConfirmationAction`，消息实体中扩展 `confirmationAction`；
  - 在 AI 回复气泡下方渲染专属操作卡片（`.aui-confirmation-card`），展示排期摘要、城市流转与起止时间；
  - 提供 **`✓ 确认应用到表格 (Apply to Table)`** 操作按钮；
  - 状态流转保持双态设计（待确认 `pending` / 已生效 `applied`）；
  - 仅在用户主动点击确认后，才通过 `onApplyTripPlans` 回调将排期写入 `modalState.tripPlans`、更新大表格分组，并异步启动后续票据字段对齐。

### 3. 出差排期缓存恢复与持久化闭环 (`v4.52.3`)
- **排期缓存覆盖底层根因彻底修复**：
  - 发现 `openBatchEditExpenseModal` 初始化步骤 7 中无条件调用了无参的 `clusterExpensesIntoTrips(modalState.groups, ...)`，导致系统每次打开弹窗都触发默认 3 天日期差聚类，并在函数末尾暴力执行 `saveTripPlansToStorage` 冲刷覆盖了用户已确认的权威排期；
  - 修复：步骤 7 优先检查 `cachedTrips`（或 `modalState.tripPlans`），若存在有效排期则以此为权威基准执行 `clusterExpensesIntoTrips(modalState.groups, ..., cachedTrips)`，杜绝无参 naive 聚类抹除权威排期缓存；
  - 批量保存成功后（`executeSaveSelected`），显式调用 `saveTripPlansToStorage(modalState.tripPlans)` 强化持久化。

### 4. 智能副驾面板 60fps 丝滑拖拽与自适应布局重构 (`v4.52.3`)
- **拖拽卡顿三大瓶颈根治**：
  - **RAF 防抖与节流**：重构 `bindAiPanelResizer`，引入 `requestAnimationFrame` 统一批处理 DOM 样式写入，设置 `pendingWidth` 过滤高频物理鼠标事件，拖拽监听器加上 `{ passive: true }`；
  - **React 内部事件风暴阻断**：拖拽期间为 `body` 添加 `.yn-resizing-active`，为面板外层添加 `.is-resizing`（禁用 CSS transition），并为 React 挂载根节点 `#yn-bem-ai-panel-react-root` 强制注入 `pointer-events: none !important; user-select: none !important;`，彻底杜绝拖拽时鼠标掠过卡片触发的海量 hover/cursor 级联重算；把手命中热区扩大至 14px；
  - **`fit-content` 布局瓶颈消除**：原 `.aui-bubble-assistant` 设定 `width: fit-content` 导致浏览器在面板宽度变化时必须递归回溯测量内部所有元素最小/最大宽度；重构为 `width: 100%; box-sizing: border-box;`；
  - **内容流自适应优化**：`.aui-markdown` 补充 `overflow-x: auto`，排期表格设定 `min-width: 480px` 保持财务严谨列排版并支持横向平滑滚动；欢迎卡片快捷建议区（`.aui-suggestions-grid`）升级为自适应 CSS Grid（`repeat(auto-fit, minmax(200px, 1fr))`），告别固定像素挤压折行。
