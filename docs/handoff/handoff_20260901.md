## 1. 本次迭代核心成果 (v4.4.0 ~ v4.4.6)

本次开发周期完成了**爱模考勤工数系统 (`time-mg.huge-vision.com`) 的全链路极速分配副驾**研发与深度工程化交付，并经历了完整的实机调试与严苛边界条件打磨：

### 1.1 爱模考勤独立子系统与架构隔离 (`src/types/timeMgTypes.ts`, `src/services/timeMgService.ts`, `src/services/timeMgAllocation.ts`, `src/services/timeMgDomService.ts`, `src/ui/timeMgModal.ts`, `src/ui/timeMgStyles.ts`)
- **多平台模式识别**：通过 URL / DOM 自适应识别 `TIME_MG` 模式与 `YUANNIAN` 模式，实现一套代码构建、独立运行隔离；
- **标准门禁智能推断**：
  - 标准工时窗口 `09:00 ~ 17:30`（7.5h，自动扣除 11:30~12:30 1h 午休）；
  - 进出门禁未完整覆盖 `09:00` 前及 `17:30` 后的工作日，100% 自动判定为 `外出`（办公地点代码 `flgOut: "1"`）；
- **严格预算保护与向下取整算法**：
  - 严格依据 0.25h 刻度向下取整（`floorToQuarterHour`），杜绝任何隐式超预算；
  - 智能多阶段装箱分配（阶段1：整天 7.5h 大块分配 ➔ 阶段2：余数零碎时段拼凑 ➔ 阶段3：预算缺口智能推荐与留空）；
- **允许超预算机制与预实对比实时监控**：
  - 左侧预实对比表提供「允许超预算」复选框，支持用户指定项目吸收全月缺口；
  - 实时高亮显示超额（`超 +XX.XXh`，红底胶囊）与剩余（`余 XX.XXh`，橙/绿底胶囊）；
- **全屏自适应与响应式排版**：
  - 模态框最大化利用屏幕空间，优化左右分栏列宽配比，出勤明细表与预实对比表支持独立滚动，运行日志默认收起；
- **Element UI 弹窗层级穿透**：
  - 动态置顶原生保存/提交确认弹窗（`z-index: 10000001`），彻底消除模态框遮挡原生确认按钮的问题。

### 1.2 关键演进：孪生客户端与宿主月份双向同步引擎 (v4.4.3 ~ v4.4.6)
- **孪生客户端架构 (Twin Client Engine)**：
  - 直连宿主 `AttendanceEdit` Vue 组件实例与 Handsontable 虚拟网格（`hotSettings.data`）；
  - 绕过不可靠的原生 DOM input 模拟，直接进行数据结构内存注入，调用 `hotInstance.loadData(hotData)` 实时整表重绘，并触发 `computeActKosu("pro")` 与宿主原生【保存】（`handleSubmit("save")`）；
- **宿主活跃年月智能嗅探与双向同步调度 (`detectActiveYearAndMonth` + `syncHostMonth`)**：
  - 页面载入时自动从 `editComp.attendance.ym`、`hotSettings.data[0].ymd` 及 DOM 嗅探宿主当前处于哪个考勤月份；
  - 在执行数据同步或一键填报前，自动调度 `syncHostMonth(year, month)` 驱动宿主无缝切换至目标月份，彻底杜绝跨月填报时因宿主表格处于其他月份导致回填 0 条并引发原生 `开始时间不能为空` 拦截的问题；
- **历史分段克隆行自动净化**：
  - 解决多次试算或分段拆分遗留的多余克隆行问题，在填报前自动对齐并从后往前清理冗余行；
- **响应式月份切换动态重算与富余工时直观呈现**：
  - 绑定 Vue 响应式 `$watch` 与 DOM 翻月监听，切换月份毫秒级刷新折叠面板表头徽章；
  - 当月预算充足时，精确计算并展示富余工时数：  
    `✓ 当月项目工时预算充足 (富余 4.74h | 总预算 162.24h / 出勤需求 157.50h)`；
  - 当月存在缺口时，展示红底警示徽章：  
    `⚠️ 当月项目工时缺口: 50.39h (总预算 107.11h / 出勤需求 157.50h)`。
