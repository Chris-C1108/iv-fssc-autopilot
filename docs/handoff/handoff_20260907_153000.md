## 1. 核心成果与关键突破

### 1.1 全局单例悬浮副驾坞 (Unified Floating Dock)
- **痛点复盘**：旧版各独立功能按钮（报销助手、出差申请、AI 副驾）使用硬编码 fixed 像素偏移（`bottom: 24px`、`85px`、`135px`），在窗口缩放、底部操作条弹出或个别按钮按规则隐藏时，易发生严重物理重叠遮挡与错位。
- **架构解法**：
  1. 单例容器 `#autopilot-floating-dock` 统一接管所有子按钮，采用 Flexbox 逆序列流（`flex-direction: column-reverse; gap: 10px;`），从 CSS 盒模型层面**物理级杜绝任何重叠**；
  2. 提供自由拖拽控制手柄，内置视口边界溢出防护（Viewport Boundary Guards），坐标自动保存至 `localStorage` (`autopilot_dock_pos`)；
  3. 支持一键折叠收起为极简迷你胶囊（`⚡ IVision 副驾 (N)`），并带动态可见功能徽标（Badge Counter），状态自动持久化 (`autopilot_dock_minimized`)。

### 1.2 按钮加载不成功问题的深度排查与根治
- **Iframe 嵌套环境穿透**：移除 Rollup 配置中的 `@noframes`，扩大 `@match` 规则；改用智能 Frame 过滤器，允许大于 250×200 的工作区 Iframe 挂载。
- **SPA 路由导航劫持**：全局代理劫持 Vue Router 的 `history.pushState` 与 `history.replaceState`，页面无刷新跳转后 100ms 内自动重新探测挂载。
- **DOM 异步渲染守卫**：注册 `MutationObserver` 监听 `document.body` 变更，一旦发现 Dock 或关键按钮被 Vue v-if 销毁重绘，毫秒级自愈复原。
