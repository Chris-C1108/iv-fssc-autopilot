## 1. 业务背景与用户诉求

用户在副驾大模型使用过程中提出了进一步的 Agentic 体验升级诉求：
1. **等待 AI 回复时的状态显示**：避免用户空等，要求提供直观的思考状态指示与演进提示；
2. **随时按钮终止 AI 输出**：输出偏差或耗时过长时，用户可随时打断流式生成，并优雅保留已生成内容；
3. **用户历史消息支持编辑修改重新发起**：输入有误或调整条件时可就地修改历史提问，系统自动回滚截断大模型底层多轮记忆并重新生成；
4. **常见 Agentic 体验标配**：一键复制并提供状态反馈、助手消息一键重试、执行耗时与模型工具性能指标徽章、输入框随内容自适应伸缩、键盘快捷键优化。

## 2. 核心架构设计与工程落地

### 2.1 实时等待状态卡片与秒表 (`createAgenticStatusCard`)
- **秒级实时跳动与阶段文字演进**：
  - 发送消息后，副驾立即在对话流末尾渲染一个带脉冲光环的 Agentic 状态卡片；
  - 启动 100ms 间隔定时器，从 `0.0s` 实时跳动显示当前生成耗时；
  - 结合大模型生命周期动态演化阶段文字（`正在思考与分析需求...` ➔ `🧠 正在深度思考与规划下一步...` ➔ `🛠️ 正在执行工具调用...` ➔ `✍️ 正在流式组织最终回复...`）；
  - 首个 SSE Token 或工具卡片到达时平滑淡出，彻底告别“黑盒卡死”等待焦虑。

### 2.2 双态终止输出与 `AbortController` 级联中断 (`src/services/llmService.ts` & `src/ui/webmcpModal.ts`)
- **发送/停止动态双态切换 (`setGeneratingState`)**：
  - 生成过程中，发送按钮无缝切换为红橙色高亮脉冲的 `⏹️ 停止` 按钮；
  - 支持键盘 `Esc` 键快捷终止；
- **级联信号中断与 Partial Content 保留**：
  - 实例化 `AbortController` 并将 `signal` 深度注入至 `callLlmAgent` 与底层 `fetch(..., { signal })`；
  - 在 SSE `reader.read()` 流式循环中捕获 `signal.aborted` / `AbortError`；
  - 严格遵守 Partial Content 优雅保留原则：不销毁已经流式挂载的文本与工具卡片，在局部内容尾部安全追加 `*(已由用户手动停止输出)*`，并将耗时指标固化保存。

### 2.3 历史消息就地内联编辑与大模型多轮记忆截断回滚
- **就地内联编辑器 (`openInlineEditor`)**：
  - 鼠标悬停用户消息气泡展示操作浮条（`📋 复制` + `✏️ 编辑`）；
  - 点击编辑后，消息气泡就地转换为多行文本域，自动聚焦并撑开高度，底部提供 `取消` 与 `保存并重新发送` 按钮；
- **数学严格的多轮会话记忆回滚 (`rollbackChatSessionToTurn`)**：
  - **用户轮次精确定位**：`targetTurn = currentUiMessages.slice(0, targetIndex + 1).filter(m => m.role === 'user').length`；
  - **大模型底层上下文回滚**：在 `llmService.ts` 中导出 `rollbackChatSessionToTurn(targetTurn)`，精准截断底层 `session.messages` 数组至该轮提问之前，彻底抹除后续无效上下文；
  - **UI DOM 截断与重发**：前端数据结构执行 `currentUiMessages.splice(targetIndex)`，DOM 树上将该条消息之后的所有兄弟节点全数移除，并将编辑后的内容作为该轮新的用户提问重新调用 `handleUserPrompt`，实现大模型记忆与前端 UI 的 100% 幂等一致。

### 2.4 Agentic 标配微交互套件
1. **一键复制与两态反馈**：点击复制后即时调用剪贴板 API，按钮短时切换为 `<span>✓</span><span>已复制</span>` 绿标高亮，1800ms 后平滑复原；
2. **助手消息一键重试 (`🔄 重试`)**：重试该轮助手回复，自动截断回滚至上一轮提问重新请求；
3. **性能指标徽章 (`.webmcp-metrics-badge`)**：生成完毕后在气泡底部显示 `⚡ 耗时 Xs · 🤖 模型 · 🛠️ N 项工具`；
4. **多行输入框高度自适应 (`autoResizeTextarea`)**：
   - 监听 `input` 事件，利用 `scrollHeight` 动态拓展文本框高度（最高 160px，溢出自动滚轮）；
   - 发送或清空后自动复原为单行（24px），兼顾大段需求粘贴与输入区域轻量化；
5. **键盘快捷键体系**：
   - `Enter`：极速发送；
   - `Shift + Enter`：换行排版；
   - `Esc`：快速终止生成。
