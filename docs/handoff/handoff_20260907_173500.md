## 1. 核心成果与关键突破

### 1.1 出差规划方案全景透视 Artifact 看板 (`src/ui/webmcpArtifactView.ts`)
- **痛点攻坚**：对话流中卡片截断导致用户无法审阅超出部分单据，无法知情决策审批；
- **全景方案透视 Artifact**：设计全屏/抽屉式全景透视看板：
  1. **5 维 KPI 汇总指标**：总申请预算（含 Buffer）、往返大交通及改签弹性预留、住宿费预估、误餐生活补贴、市内交通出租车 Buffer；
  2. **全量单据结构化对比表**：Trip 1 ~ Trip N 一屏横向对比出行人、目的地、起止天数与各项费用拆解；
  3. **多行旅程树穿透**：可一键展开查看去程/返程的所有明细行与合报人员标注；
  4. **全渠道导出与就地审批**：支持一键导出 JSON 方案数据、复制 Markdown 规划总表，并支持就地点击 `[✅ 批准并提交入库]`。

### 1.2 零截断展开/收起卡片交互 (`src/ui/webmcpModal.ts`)
- 默认展示前 3 张，下方提供现代化切换胶囊：`[ ▼ 展开其余 N 张单据明细 (共 M 张) ]` ⇄ `[ ▲ 收起部分卡片 ]`；
- 单卡右上角增加 `[明细 ▼]` 开关，点击即可原地展开查看该单据的费用拆解与所有往返行程明细。

### 1.3 批量创建草稿 0 成功 6 失败根因根除与防御
- **申请人括号清洗与登录人自适应**：正则剥离形如 `(ITS)`、`（外驻）` 等多余后缀，精准匹配登录人主数据 ID（`state.applicantId`），彻底杜绝纯文本字符串写入外键导致数据库校验失败；
- **缺项目时的科目联动容灾保护**：严格限制仅在成功解析到项目时才联动切换为 `项目预算`；若未选项目，保留模板原有的合法差旅科目（`国内出張旅費`），彻底解决“项目必填”规则拦截；
- **真实错误诊断与拒绝虚假提示**：`fssc_batch_create_trip_drafts` 全程捕获具体失败报错并存入 Trajectory 运行轨迹；前端在发生失败时严禁显示虚假“恭喜”，而是展示警告卡片并列出每笔单据的具体报错。
