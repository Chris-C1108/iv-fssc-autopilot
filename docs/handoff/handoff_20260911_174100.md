1. **「✨ AI智能推断」按钮联动**：

3. **彻底清除旧模态框**：
   - 明确不再需要之前的“出差行程排期辅助推断”及行程信息整理的模态框 (`openItineraryModal` / `#yn-bem-itinerary-mask`)，所有行程粘贴、大模型推理与推断操作完全统一收敛至 AI 助手侧边栏中完成。

## 2. 攻坚要点与技术方案

### 2.1 状态契约与 Skill 技能体系定义 (`src/ui/batchEditExpenseModal.ts`)
1. **定义 `AiSkillItem` 契约**：
   - `id`: 唯一技能标识；
   - `command`: 快捷指令（`/infer`、`/itinerary`、`/proxy`、`/audit`、`/template`）；
   - `name`: 技能名称；
   - `icon`: 技能图标；
   - `summary`: 简述；
   - `hintTitle` & `hintText`: 输入框上方辅助指引横幅；
   - `promptTemplate`: 动态生成带当前所选条目数、项目号与社员名的标准提示词模板。
2. **在 `BatchEditExpenseModalState` 注入技能状态**：
   - `activeSkillId: string | null`；
   - `skillMenuOpen: boolean`；
   - `slashMenuOpen: boolean`；
   - `slashQuery: string`；
   - `slashSelectedIndex: number`。

### 2.2 呼出侧边栏与技能注入器 (`openAiAssistantWithSkill`)
- 若当前未选中任何条目，自动全选当前筛选视图内的全部费用条目；
- 激活并展开 `100vh` 侧边栏，大表格自适应 `marginRight`；
- 激活费用上下文胶囊与目标 Skill 徽标；
- 在输入框上方渲染带有微边框的指引横幅（含一键【📋 复制排期模板】按钮）；
- 自动填充技能模板提示词并聚焦至末尾。

### 2.3 双轨 Skill 交互机制
1. **输入框底部 `⚡ 技能 ▾` 按钮与下拉列表**：
   - 位于 `＋` 附件按钮右侧；
   - 点击切换弹出式菜单，点击任一技能立即激活并注入提示词。
2. **输入框 Slash Command (`/`) 自动补全**：
   - 监听输入框 `input` 事件，当匹配以 `/` 结尾时，在输入框上方悬浮弹出 `.yn-gemini-slash-menu`；
   - 监听 `keydown` 事件：
     - `ArrowDown` / `ArrowUp`：循环切换高亮项；
     - `Tab` / `Enter`：消除 `/` 并采纳当前高亮技能；
     - `Escape`：关闭菜单。

### 2.4 会话流多模态行程识别与智能推断闭环
- 当用户在侧边栏发送指令时：
  - 自动检测输入文本是否包含日程表格（如 Excel 复制的制表符或 Markdown 表格）；
  - 若识别到权威出差日程，自动调用 `parseItineraryTable` 聚类至 Trip 轮次，大表格自动切换为 `TRIP` 分组；
  - 随后自动调度 `handleAiInference(container, text)` 进行证据链推断，并在会话流中实时反馈。

### 2.5 彻底移除旧模态框与死代码清理
- 物理删除 `openItineraryModal`（244 行旧 DOM 生成与事件代码）；
- 移除样式表中 `#yn-bem-itinerary-mask`、`.yn-bem-itinerary-card` 等冗余样式；
- 将浮岛按钮 `#yn-bem-island-btn-ai`、快捷气泡 `#yn-gemini-chip-infer`、`#yn-gemini-chip-itinerary`、`#yn-bem-btn-ai-infer` 全部重定向至 `openAiAssistantWithSkill`。
