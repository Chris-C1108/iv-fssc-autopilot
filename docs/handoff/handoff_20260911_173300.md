## 2. 攻坚要点与技术方案

### 2.1 性能根因排查与现代 Web 加速架构 (根除丢帧卡顿)
- **根因 1：`expenseRecordDomService.ts` 全局 MutationObserver 级联雪崩**：
  - 宿主页面的 `MutationObserver` 监听了 `doc.body` 的全部变动。
  - 弹窗内折叠/展开分组、切换模式或编辑时产生的大量子 DOM 变动触发后台 `scanAndEnhanceExpenseRecordDOM`，遍历后台列表的 React Fiber 树，造成 CPU 100% 满载。
  - **解决方案**：在 Observer 第一行注入过滤守卫，凡是目标属于 `#yn-batch-edit-modal` 或 `#autopilot-floating-dock` 的变动彻底直接 `return` 拦截；同时隔离主文档的 `click` 和 `change` 监听器。
- **根因 2：大表格 35 列并发 CSS Transition 造成光栅化重绘阻塞**：
  - `.yn-bem-table tbody td` 原有 `transition: background-color 100ms var(--coss-ease)`。
  - 鼠标扫过表格时瞬间激活数百个非合成层动画，CPU 重绘耗时剧增。
  - **解决方案**：移除 `td` 上的 `transition: background-color`，采用现代高效瞬时 `:hover` 背景；表格启用 `table-layout: fixed;` 锁定列宽杜绝整表 Reflow；分组 `tbody` 引入现代标准 `content-visibility: auto; contain-intrinsic-size: 0 42px;` 实现视口外跳过绘制（Offscreen Culling）。

### 2.2 发票张数单元格徽章移除
- 彻底移除了 `${group.invoiceCount > 1 ? \`<div class="yn-bem-multi-inv-badge">\${group.invoiceCount}张发票合并</div>\` : ''}`，并在样式表中清理相关规则，保持纯数字清爽显示。

### 2.3 单元格输入框 100% 满高贴合 (图 1 修复)
- 移除 `td.yn-bem-cell-interactive` 外层内边距（`padding: 0 !important; height: 1px !important;`）；
- 输入框 (`.yn-bem-dyn-input`, `.yn-bem-desc-input`, `.yn-bem-cell-date-input`, `.yn-bem-cell-text-input`) 统一设为 `width: 100%; height: 100%; min-height: 34px; box-sizing: border-box; border-radius: 0; padding: 0 8px; border: 1px solid transparent;`；
- 聚焦时采用 `box-shadow: inset 0 0 0 2px #2563eb !important; border-color: #2563eb !important; background: #ffffff !important;`，呈现贴合单元格边界的高质感聚焦环。

### 2.4 顶部两行专用布局
- **行 1 (`.yn-bem-top-row-1`)**：
  - 左侧：标题 `批量修改费用信息` (+ 差异检测微标签) + 分组模式选择器 `分组: [按 Trip 轮次 ▾] [展开] [折叠]`；
  - 右侧：搜索框 `搜索...` + `✦ AI 助手` 切换按钮 + 关闭按钮 `✕`。
- **行 2 (`.yn-bem-top-row-2`)**：
  - `[全选]` `[全不选]` `[反选]` `[仅选待补 (N)]` `[仅选预警 (M)]` + 筛选下拉模式 `[全部 (X) ▾]` + 活跃列筛选 Tags。

### 2.5 AI 助手侧边栏全屏视口贯通 (`100vh`) 与自适应拖拽宽度
- 高度设为 `100vh` 满高 (`position: fixed; top: 0; right: 0; bottom: 0; height: 100vh; z-index: 999999;`)；
- 左边缘注入自适应拖拽分割条 `<div class="yn-bem-ai-resizer" id="yn-bem-ai-resizer"></div>` (`cursor: col-resize`)；
- 支持实时无级拖拽调整宽度（320px ~ 85vw），宽度存入 `localStorage` (`yn_fssc_ai_panel_width`)；
- 主内容容器挂载平滑过渡（`transition: margin-right 0.25s`），展开时平滑向右避让，绝不遮挡表格和底栏。
