## 1. 核心需求与背景

针对用户在出差规划流程中提出的三项核心痛点，本次迭代完成了系统级落地：
1. **Q1 历次交接不可变追溯**：废止单日覆盖的 `handoff_20260907.md`，按 `AGENTS.md` 规范重构为 `handoff_YYYYMMDD_hhmmss.md` 时间戳不可变序列（已归档 120000, 153000, 170000, 173500 并在 `README.md` 中完整索引）。
2. **Q2 A2UI 预算归属交互决策**：当用户在自然语言中未提及是否使用项目预算时，副驾主动呼出 A2UI 决策卡片（提供「部门日常出差」与「研发/实施项目出差」切换），并配套提供防抖动态项目检索框与候选下拉菜单，实时将选定项目双向同步至内存单据与视图，零硬编码。
3. **Q3 人员消歧与正社员报销人规约**：
   - **同名消歧**：如当前用户存在 `陈浩` 与 `陈浩-ITS` 同名人员，基于评分加权系统（精确全字匹配 100 分、限定符匹配 +60/-40、纯同名正社员防误杀 -30），精准消歧并存入候选池；修复此前将带限定符的外驻人员误劫持为登录正社员的判定漏洞；
   - **报销人正社员硬规约**：在合报模式（`combineTripsForMainApplicant`）中，报销人强行锚定为当前登录的正社员，即便全团出差人员全为外驻，申请单报销人始终为该正社员，外驻人员作为实际出差人（标注于 F_FLIGHT 班次及 travelers 字段中）。

## 2. 关键代码变更清单

### 2.1 新增模块 `src/ui/webmcpA2Ui.ts`
- **通用 A2UI 决策卡**：`renderA2UiProjectDecisionWidget`，支持：
  - 部门日常出差（科目为「国内出張旅費」，不占用项目预算）；
  - 研发/实施项目出差（自动展开检索框，300ms 防抖请求元年云 `/fssc/dim/dimObject/getDimObjectAccessTree` 项目维表）；
  - 候选下拉浮层：展示项目代码、项目名称，点击即选即用；
  - 内存配置双向更新：修改 `configs.forEach(c => { c.projectName = ...; c.projectVO = ...; })` 并触发视图微更新。

### 2.2 服务层升级 `src/services/applicationService.ts`
- **人员同名消歧与限定符结构化解析** (`fetchPersonnelVO`)：
  - 结构化提取 `baseName` 与 `qualifier`（如 `陈浩-ITS` 拆分为基础名 `陈浩` 与限定符 `ITS`）；
  - 登录人绑定判定优化：仅在纯姓名或无限定符冲突时直接绑定为登录正社员，明确带有限定符的转入维表消歧；
  - 候选人评分排序：精确匹配、限定符权重、无限定符同名正社员防误选扣分；
  - 候选人追踪池：存入 `state.tripApp.personCandidates`。
- **项目列表动态检索** (`searchProjectList`)：
  - 动态检索 `TRIP_CONSTANTS.projectDimObjectId` 项目维表，返回 `{ id, code, name, vo }`。
- **合报主申请人强规约** (`combineTripsForMainApplicant`)：
  - 锁定 `applicant = defaultMain || (allTravelers[0] || '当前用户')`，移除当 `allTravelers` 不包含正社员时回退为外驻人员的旧逻辑；
  - 精确标记 `isProxy = !allTravelers.includes(applicant)` 与 `isCombined`。
