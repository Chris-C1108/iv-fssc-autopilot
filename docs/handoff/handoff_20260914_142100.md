## 一、本次交接演进清单与核心突破

### 1. 员工同名消歧（Homonym Disambiguation）与申请人精准绑定 (`v4.61.0`)
- **同名员工真相调查**：
  - 系统员工维表（`getDimObjectAccessTree`）证实存在两位真实姓名相同的社员：
    - **员工 A**：`陈浩`（工号 `20061009`，部门 `资源中心-第1Unit`，ID `0355c717a27345af7f1906ec05cc0001`）
    - **员工 B (当前登录社员)**：`陈浩（ITS）`（工号 `20160705`，部门 `资源中心-第2Unit`，ID `11eee047a80566bca18367ceb209b2e1`）
- **故障成因链路根治**：
  1. **前端嗅探保留全名**：`src/ui/batchEditExpenseModal.ts` 中 `detectCurrentEmployeeName` 停止盲目过滤括号，优先返回带部门后缀的官方全称（如 `陈浩（ITS）`），保证下游消歧具备唯一凭据；费用说明模板提取纯名（`陈浩`）保持单据摘要简洁；
  2. **基础名自适应比对**：`src/services/applicationService.ts` 中 `fetchPersonnelVO` 增加 `loginBaseName`（`"陈浩"`）。当输入纯名且与登录人基础名一致时，只要未显式传入冲突限定符，直接锁定当前登录社员；
  3. **维表打分与 ID 提取修正**：修正树节点候选人 ID 获取路径为 `candId = item.data?.objectId || item.key || item.data?.accountId || item.id`（解决原 `item.data.accountId` 为空字符串导致保底加分失效的 Bug）；命中当前登录人赋予 `+500` 绝对优先分，且豁免括号扣分；
  4. **自办单据刚性守卫**：`createSingleTripApplicationApi` 在非代办（`!config.isProxy`）场景下，强行锁定 `state.applicantId` 和 `loginUser.userName`，绝不允许调入同名外部人员。
- **线上草稿原地修复**：
  - 线上全量 7 批次申请单草稿（`SC26090054` ~ `SC26090060`）及附测单据 `SC26090061` 的 `APPLICANT_ID`、`USERS_ID`、`CREATOR_ID` 已 100% 更新为 `陈浩（ITS）` 并写入数据库。

### 2. 出差时间精细化至 `hh:mm` 与默认 09:00 / 23:59 规则 (`v4.60.0`)
- **时间精度规则**：
  - 优先级 1：关联发票 OCR 票面时间（`timeGetOn` / `departureTime` / `timeGetOff`）；
  - 优先级 2：费用说明自然语言时间抽取；
  - 优先级 3：刚性兜底 — 出发时间默认 `09:00`，归宅时间默认 `23:59`（格式：`YYYY-MM-DDTHH:mm`）；
- **全表同步联动**：
  - SC 出差申请单：表头 `START_TRIP_DATE` / `END_TRIP_DATE` 及大交通行程明细子表（Legs）；
  - BC 出差费用报销单：表头 `START_TRIP_DATE` / `END_TRIP_DATE` 及出差报告子表（`T_BILL_AREA_BGQ_DEF_001`）`F_QJFROM` / `F_TOQJ`。

### 3. 报销单【出差申请单】、【费用归属】台账机制权威解答
- **宿主台账额度锁止机制**：
  - 报销单 `F_CCSQD` 是 `MACHINE_ACCOUNT`（台账关联对象）；
  - 宿主系统台账池接口 `/fssc/machaccount/relationMachineAccount/getBillRelationMachAccountData` **仅对已审批通过（`APPROVED`/`EFFECTIVE`）的申请单开放可用额度**；
  - 草稿态（`UNCOMMITTED`）的申请单在官方台账池中可用额度客观为 0，因此报销单分摊子表中的【申请单号】与【可用金额】在审批通过前显示为 `-` 空，属于合规台账锁定机制；
- **费用归属蝴蝶效应自动回填**：
  - 报销单保存时，副驾对首行触发蝴蝶效应计算（`fieldValueChange`），科目设为 `项目预算`，项目设为对应项目（如 `X2607-001`），`F_SFXKHQK` 设为【是】，自动推导记账科目（`500150`），并内存极速克隆至全量费用行。
