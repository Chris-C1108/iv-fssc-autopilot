## 1. 核心成果与关键突破

### 1.1 Google AI Studio (Gemini API) 503 网关超载异常根治
- **痛点复盘**：用户上传 5 张高分辨率行程单截图（`IMG_4308.PNG`、`IMG_4309.jpg`、`携程-机票清单.png` 等），旧版直接转为原始 Base64 发往 Google AI Studio，单个 JSON 请求体高达 15MB~30MB，导致 Google 网关报错 `HTTP 503: The model is overloaded`。
- **攻坚解法**：
  1. **前端 Canvas 智能等比下采样 (`compressImageFile`)**：限制最大边长 1600px，保留发票与机票 OCR 关键文字锐度，以 0.82 质量压缩为高质量 JPEG，将单图 3~8MB 缩减至 120~220KB，5 张图片总 Payload 降至 1MB 以内（体积削减 95%）；
  2. **Google AI Studio 专属预设**：新增官方预设与端点适配，支持 `gemini-1.5-pro`、`gemini-2.0-flash`、`gemini-1.5-flash`；
  3. **3 级指数退避与抖动重试 (Exponential Backoff)**：遇 503/429 依次等待 2s、4s、6s 重试最多 3 次。

### 1.2 DeepSeek Harness 风格 Trajectory 运行轨迹查看器
遵循 [DeepSeek Harness (dsh)](https://github.com/deepseek-ai/deepseek-harness) 核心架构哲学：*“Every run is traceable. Everything the model sees is recorded in an append-only session log.”*
- **唯一事实源 (Append-Only Event Stream)**：不可变单向追加事件流，划分 9 大标准来源：`SYSTEM`、`USER`、`CONTEXT`、`REASONING`、`MODEL_OUTPUT`、`TOOL_CALL`、`TOOL_RESULT`、`SUBAGENT`、`ERROR`；
- **全交互式查看器**：支持按 Source 快速过滤、全文毫秒级检索、时序单步平滑回放 (Replay)、单事件与全量 JSON 复制及一键下载 `trajectory-<runId>.json`。

### 1.3 全仓零硬编码安全审计
- 全仓执行 `grep_search` 审计，彻底消除测试人名、项目与测试日期常量，业务完全由维表与登录人上下文动态驱动。
