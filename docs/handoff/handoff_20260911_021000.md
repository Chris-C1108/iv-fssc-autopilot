| **4** | **BUG 3：大表格临时保存 Trip 信息，方便用户打磨为申请单、出差报告与报销单** | 之前 Trip 仅在内存易失保存，刷新或重开即丢失；用户无法在表格中微调 Trip 字段，也无法便捷导出业务报告。 | **Trip 暂存打磨体系与 Markdown 报告生成器**：<br>• **LocalStorage 暂存**：`saveTripPlansToStorage` 与 `loadTripPlansFromStorage`，弹窗重开自动恢复；<br>• **组表头微按钮**：每个 Trip 组表头注入 `✏️ 编辑/打磨 Trip` 与 `📄 出差报告草稿`；<br>• **Trip 编辑浮层 (`openEditTripModal`)**：就地微调目的地、起止日（联动重算天数与误餐补贴）、酒店、走访据点、同行人及预算，并实时同步费用归集与暂存；<br>• **出差报告草稿一键导出**：一键生成结构化出差总结 Markdown（含出差基本信息、费用报销核算与工作成果），直拷剪贴板。 |

## 2. 关键代码变更清单 (Code Changes)

### 2.1 `src/services/inferenceService.ts`
- 实现了 `parseItineraryWithAi(itineraryText: string, signal?: AbortSignal): Promise<DynamicTripInput[]>`；
- 定义 `ITINERARY_PARSER_SYSTEM_PROMPT`，明确往返闭环定义、多波次同目的地日期隔离、标准化 YYYY-MM-DD，严格遵循 AGENTS.md 反硬编码铁律。

### 2.2 `src/ui/batchEditExpenseStyles.ts`
- 补全全景看板浮层 CSS（`.yn-bem-decision-modal-overlay`、`.yn-bem-decision-modal`、`.yn-bem-decision-modal-header` 等）；
- 优化排期推荐卡片为两行式布局（`.yn-bem-itin-rec-item`、`.yn-bem-itin-rec-item-header`、`.yn-bem-itin-rec-item-details`）；
- 增加组表头微按钮样式（`.yn-bem-btn-trip-edit`）；
- 增加 Trip 深度打磨编辑器浮层全套 CSS（`#yn-bem-edit-trip-mask`、`.yn-bem-edit-trip-card`）。

### 2.3 `src/ui/batchEditExpenseModal.ts`
- 接入 `parseItineraryWithAi` 与 `MODAL_STYLES`；
- 增加 LocalStorage 暂存体系：`saveTripPlansToStorage`、`loadTripPlansFromStorage`、`clearTripPlansFromStorage`；
- 在 `openBatchEditExpenseModal` 初始化时自动恢复暂存 Trip；
- 落地 `openEditTripModal` 支持用户就地打磨 Trip 详情与预算微调联动；
- 落地 `generateTripReportMarkdown` 导出出差总结报告；
- 组表头渲染 `✏️ 编辑/打磨 Trip`、`📄 出差报告草稿` 并绑定点击代理；
- 全景复核看板挂载至 `targetDoc.body` 并注入打磨与报告按钮。

### 2.4 `package.json`
- 遵循规约，版本从 `4.40.0` 递增至 `4.41.0`。
