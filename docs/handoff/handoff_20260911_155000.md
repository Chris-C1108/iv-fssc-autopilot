## 一、架构决策与背景回顾 (Context & ADR)

### 1. 为什么坚决拒绝 HeroUI？
- **宿主样式污染 (Host Contamination)**：HeroUI 强依赖 Tailwind CSS v4，其 Base Reset / Preflight 会强制重置宿主 `ync37.yuanian.com` 全局的 `button`、`input`、`table`、`body` 样式，导致企业原生 Ant Design 表格与导航栏大面积崩溃；
- **Portal 浮层脱节**：基于 React Aria 的浮层组件默认挂载至 `document.body`，在 Shadow DOM 或 Userscript 环境下会脱离作用域导致样式丢失；
- **构建体积膨胀**：全量打包 HeroUI + Tailwind + React Aria 会导致单文件油猴脚本暴增数兆字节，严重拖慢注入耗时。

### 2. 为什么选型 `coss.com/ui` 并按现代平台标准吸收？
- **业务场景对齐**：`coss.com/ui` 是 Cal.com 开源企业级调度系统的官方组件库，专注于高密度输入、数据表格与生产力表单，与我们财务报销大表格、出差行程规划的场景完美契合；
- **GoogleChrome/modern-web-guidance 对齐**：倡导 Web 平台原生能力（CSS Variables、CSS Transitions、Compositor-only 动画），无 Framer Motion 运行时负担；
- **Vercel Web Design Guidelines 对齐**：严格单色优先、1px 微细边框（`rgba(0,0,0,0.08)`）、等宽数字（`font-variant-numeric: tabular-nums`）、2px 焦点环（`:focus-visible`）；
- **组件即源码 (Component-as-Code / Zero NPM Runtime)**：采用严格命名空间（`.yn-coss-*`, `.yn-bem-*`）与内部注入，确保 **100% 零外部破坏性依赖，100% 宿主零污染**。

### 1. 设计令牌体系 (`src/ui/batchEditExpenseStyles.ts`)
在 `#yn-batch-edit-modal` 内部严格作用域注入：
- **表面与背景色**：`--coss-bg-base: #ffffff`, `--coss-bg-surface: #fafafa`, `--coss-bg-muted: #f4f4f5`, `--coss-bg-subtle: #f9fafb`；
- **前景色阶梯**：`--coss-fg-default: #09090b`, `--coss-fg-muted: #52525b`, `--coss-fg-subtle: #71717a`；
- **微边框阶梯**：`--coss-border: rgba(0, 0, 0, 0.08)`, `--coss-border-hover: rgba(0, 0, 0, 0.16)`；
- **语义色彩**：`--coss-primary: #18181b`, `--coss-success: #059669`, `--coss-warning: #d97706`, `--coss-danger: #dc2626`, `--coss-info: #2563eb`；
- **微按压与硬件加速缓动**：`--coss-ease: cubic-bezier(0.16, 1, 0.3, 1)`。

### 2. 标准原子组件系统 (`.yn-coss-*`)
- **`.yn-coss-btn` 按钮族**：
  - 包含 `default`, `secondary`, `outline`, `ghost`, `danger`, `ai` 全套变体；
  - 具备 `:active:not(:disabled) { transform: scale(0.98); }` 微按压物理回弹；
  - 具备 `:focus-visible { box-shadow: 0 0 0 2px var(--coss-bg-base), 0 0 0 4px var(--coss-ring); }` 高能见度无障碍双环；
- **`.yn-coss-badge` 状态徽标族**：
  - 包含 `default`, `secondary`, `success`, `warning`, `danger`, `info` 变体；
  - 统一应用 `font-variant-numeric: tabular-nums`；
- **`.yn-coss-input` / `.yn-coss-select` 表单控件**：
  - 极细 1px 微边框，聚焦平滑过渡至 `--coss-primary`，提供 1px 内发光轮廓。

### 3. 既有组件现代化升级
- **顶栏与操作区**：
  - `⚙️ 批量设置` 与 `✦ AI 助手` 按钮集成 `--coss-*` 按钮体系，激活时呈现深黑高对比沉底；
  - 格式预设（`[外驻:人名] 项目 备注` 等）选项卡升级为 `coss.com/ui` Segmented Control 质感；
  - 搜索框与下拉选择框聚焦时平滑环绕；
- **Gemini AI 侧滑面板**：
  - 4 大快捷建议气泡（`yn-gemini-chip-btn`）升级为 coss Pill Button 样式，微上浮与柔和投影；
  - 底部输入框（`yn-gemini-input-pill`）升级为全圆角药丸框，聚焦高亮平滑；
- **财务表格 (Evidence Table)**：
  - 表头 `th` 注入 `--coss-bg-surface` 与精细边线；
  - 表格数据单元格 `td` 全面挂载 `font-variant-numeric: tabular-nums;`，金额、发票号、日期等宽对齐；
  - 底栏选中汇总（`¥XXX.XX`）等宽醒目对齐。
