## 1. 核心需求与背景

用户在元年云费控系统的【发票夹】上传发票后，系统 OCR 识别后存入“未使用发票”列表。存在因 OCR 无法识别发票金额（金额为 0）、缺失开票日期、缺失发票号码等问题，导致后续记费用、报销被系统阻断或退单。

插件需要：
1. 智能校验发票信息是否完备，识别出缺少必要字段（金额、日期、号码）的发票；
2. 在发票夹原生表格直观标注与高亮，并提供一键修改指引；
3. 彻底根治胶囊徽章与【修改】按钮导致的**布局挤压、变形和抽搐抖动**，实现零回流（Zero Reflow）与双/三表像素级对齐。

---

## 2. 核心成果与关键技术突破

### 2.1 抽搐与抖动三大根因彻底根除
1. **MutationObserver 自死锁阻断**：
   - 引入全局 `isScanning` 互斥锁；
   - Observer 回调白名单过滤插件自身元素（`#yn-invoice-audit-toolbar`、`.yn-invoice-badge`、`data-yn-badge`、`#yn-injected-styles`），仅在真实 `TR` 挂载/卸载时响应防抖重扫。
2. **零边距原位高亮（彻底消除挤压与换行）**：
   - 【修改】按钮保持原生 `display: inline !important;`、`margin: 0 !important;`、`padding: 0 !important;`；
   - 纯文字高亮：加粗、鲜亮红 `#ff4d4f`、下划线；
   - 与原生【查看】【删除】严格处于同一行，100% 杜绝换行撑破固定列；
   - 单元格徽章尺寸锁定为 `height: 16px !important; line-height: 16px !important; display: inline-block !important;`；
   - 边框采用 `box-shadow: inset 3px 0 0 #ff4d4f !important;`，盒模型 0 变形。
3. **三表像素级行高同步**：
   - Ant Design Vue 表格包含 `.ant-table-scroll`、`.ant-table-fixed-left` 与 `.ant-table-fixed-right`；
   - `processTableRow` 同时同步三表的行状态与过滤隐藏，实测 `maxDiff = 0`，全行锁定 36px 原生行高。
4. **工具栏容器解耦**：
   - 将 `#yn-invoice-audit-toolbar` 挂载在 `.btn_overflow_leftArea` 外层 flex 容器中，作为 `.rc-overflow` 的同级元素，彻底避免干扰 rc-overflow 内部宽度测量与 ResizeObserver。

## 4. 实机验收结论

- **实测环境**：Chrome 标签页 `846843610`（发票夹 53 条真实发票）。
- **实测结果**：

  - 静态页面 100% 零抽搐、零抖动、零 Mutation 死循环；
  - 勾选「仅看残缺」后瞬间无缝过滤，仅保留 1 条残缺发票，取消后 100% 完整复原。
