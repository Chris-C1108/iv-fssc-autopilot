## 2. 关键架构决策与红线遵从

1. **绝对禁止自动提交审批流 (Commit Guard Iron Law)**：
   智能副驾在极速建单流水线中，全流程严格锁定 `commit: false`，仅作为草稿保存入库。单据提交进入审批流的权利严格保留由用户在系统 UI 界面人工复核后手动点击完成。
2. **反硬编码铁律 (Anti-Hardcoding Iron Law)**：
   绝不硬编码任何私有业务实体（如客户/工厂名、人员姓名工号、私有项目号、静态城市字典）。所有实体推断均基于发票 native 字段、维表接口和用户显式上下文，满足换人、换城、换客 100% 通用性。
