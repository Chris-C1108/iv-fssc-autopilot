## 2. 架构设计与关键技术落地

### 2.1 大模型 SSE 增量流式解析核心 (`src/services/llmService.ts`)
- **Web API ReadableStream 逐行解析**：
  - 调用 `fetch(url, { ...payload, stream: true })`；
  - 基于 `reader.read()` 和 `TextDecoder('utf-8')` 实现行缓冲解析器；
  - 增量抽取 `data: {"choices":[{"delta":{"content":"..."}}]}`，并通过 `onStreamDelta` 实时推送累积文本；
- **流式工具调用聚合 (`toolCallsMap`)**：
  - 当大模型在流式输出过程中触发工具调用时，参数分片随 `choice.delta.tool_calls` 逐块送达；
  - 实现基于 `index` 的参数拼接还原器，完美支持边流式思考边发起工具调用；
- **边界与降级保护**：
  - 遇到 `data: [DONE]` 顺利结束流，并在不支持流式或网络异常时自动平滑回退至非流式 `res.json()`。

### 2.2 markstream-react 渲染引擎与 React 19 挂载封装 (`src/ui/markdownRenderer.ts`)
- **打字机动态流式挂载器 (`mountStreamingMarkdown`)**：
  - 在油猴 DOM 沙盒中使用 `react-dom/client` 的 `createRoot(container)` 挂载 `<Markdown content={text} smoothStreaming={true} final={isFinal} />`；
  - 导出 `{ update(text, isFinal), destroy() }` 句柄，随 SSE 块实时触发 React 调度；
- **历史会话与卡片静态渲染器 (`renderStaticMarkdown`)**：
  - 会话抽屉历史切换、离线消息复原时使用同一渲染引擎生成静态 DOM，体验完全一致；
- **样式沙盒与内联注入 (`src/ui/webmcpStyles.ts`)**：
  - 在 Rollup 编译期将 `markstream-react/dist/index.css` 读取并通过 `__MARKSTREAM_CSS__` 注入到顶层 `<style>`，保证表格线框、字号边距、暗色/亮色自洽。

### 2.3 油猴单文件 IIFE 动态 Import 与代码分割破解 (`rollup.config.mjs`)
- **踩坑现象**：`markstream-react` 内部包含对 `mermaid`、`katex`、`d2` 等重型库的可选动态导入 `import(...)`，Rollup 在 IIFE 格式下默认报错阻止编译；
- **终极破解方案**：
  1. `output.inlineDynamicImports: true`：强制将动态 import 合并至单文件主包；
  2. `stubOptionalDependencies` 插件：将 6 个可选外部依赖拦截并 resolve 至虚拟 Stub 模块（`export default null;`）。既消除了 Rollup 的 Unresolved 警告，又杜绝了浏览器控制台报错。
