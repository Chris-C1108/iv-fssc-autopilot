## 3. Critical Pitfalls & Hard Lessons Learned

Consolidated in [`docs/lessons/LESSONS_AND_PITFALLS.md`](../lessons/LESSONS_AND_PITFALLS.md):
1. **Never hand-craft synthetic `billSceneDataVO`**: Always clone `currentBillData` directly with only `delete clone.billButtons`.
2. **`fieldValueChange` vs `saveBillData`**: `fieldValueChange` only computes in session memory; `saveBillData` writes to database.
3. **Single-Bill Concurrency**: Rows in the same bill share a single `version` lock. Use in-memory cloning instead of concurrent HTTP requests.
4. **OCR Data Restoration**: Pierce invoice pool `getInvoiceByDataId` to restore `timeGetOn` / `timeGetOff` / `mileage` before saving.
